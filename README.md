# Coredence for Scoop

```powershell
scoop bucket add coredence https://github.com/coredence/scoop-bucket
scoop install coredence
coredence start
```

This installs the Coredence engine and command line. The desktop window comes with the installer from [coredence.com](https://coredence.com/download).

Coredence is not open source. This repository holds only the Scoop manifest; the package is downloaded from the [official release](https://github.com/coredence/coredence/releases) and checked against its SHA-256.
